# Financeiro ENTUR

Sistema financeiro da **Escola de Negócios do Turismo (ENTUR)**.

Stack: Next.js 15 (App Router) · TypeScript · Tailwind · Prisma · PostgreSQL · NextAuth.

## Fases

- **Fase 1 — Foundation** (esta versão): schema completo de 22 entidades, auth com roles, sidebar com 20 módulos, dashboard executivo agregando KPIs do banco, seed inicial com categorias/centros/produtos ENTUR.
- **Fase 2** — Cadastros core: clientes, produtos, fornecedores, categorias, centros, contas bancárias (CRUD).
- **Fase 3** — Receitas, parcelamentos, assinaturas, contas a receber, inadimplência.
- **Fase 4** — Despesas, contas a pagar, comissões.
- **Fase 5** — Dashboard com gráficos, DRE gerencial, fluxo de caixa, conciliação.
- **Fase 6** — 20 relatórios, exportação CSV/Excel, auditoria, importação CSV, alertas.

## Deploy

Rodando no Coolify (projeto `FINANCEIRO-ENTUR`) atrás de PostgreSQL gerenciado.
